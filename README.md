# Handle both json and xml formats
Returning JSON and XML format from exact same method is handled automatically through Content Navigation.
Spring inspects the Accept header of incoming HTTP Request (eg. Accept: application/json Vs. 
Accept: application/xml) and serializes our object into requested format.
